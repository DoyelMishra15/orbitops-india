# API Reference

Base URL (local dev): `http://localhost:8000/api/v1`

Interactive OpenAPI docs are auto-generated by FastAPI at `/docs`
(Swagger UI) and `/redoc` when the backend is running.

---

## `GET /health`

Health check.

**Response 200**
```json
{ "status": "ok", "service": "OrbitOps India", "version": "1.0.0" }
```

---

## `GET /data-source/status`

Reports whether the app is running in live or demo/archive TLE mode.

**Response 200**
```json
{
  "mode": "demo_archive",
  "provider": "Local archived fixture (SGP4 reference vector, offline demo mode)",
  "last_refreshed": "2026-07-11T12:00:00Z",
  "satellite_count": 1,
  "message": "Offline demo/archive mode: serving a single scientifically verified reference TLE..."
}
```

---

## `GET /ground-stations/presets`

Returns illustrative demo ground-station locations (see
`docs/DATA_SOURCES.md`).

---

## `GET /satellites?q=<query>`

Lists satellites in the current catalogue (live or demo). Optional `q`
filters by name substring or exact NORAD ID.

---

## `GET /satellites/{norad_id}`

Returns a single satellite summary, or `404` if not present in the
current catalogue.

---

## `POST /passes/predict`

**Request body**
```json
{
  "norad_id": 5,
  "ground_station": {
    "name": "Bhubaneswar Demo",
    "latitude_deg": 20.2961,
    "longitude_deg": 85.8245,
    "altitude_m": 45.0,
    "min_elevation_deg": 10.0
  },
  "start_time_utc": "2026-07-12T00:00:00Z",
  "duration_hours": 48
}
```

Constraints: `duration_hours` must be > 0 and ≤ 168 (7 days).
`start_time_utc` must be timezone-aware (ISO-8601 with offset/`Z`).

**Response 200**
```json
{
  "norad_id": 5,
  "satellite_name": "VANGUARD 1 (SGP4 REFERENCE VECTOR)",
  "ground_station": { "...": "..." },
  "data_mode": "demo_archive",
  "window_start_utc": "2026-07-12T00:00:00Z",
  "window_end_utc": "2026-07-14T00:00:00Z",
  "passes": [
    {
      "aos_utc": "...",
      "los_utc": "...",
      "max_elevation_utc": "...",
      "max_elevation_deg": 42.7,
      "duration_seconds": 612.0,
      "aos_azimuth_deg": 310.2,
      "los_azimuth_deg": 95.4,
      "max_elevation_azimuth_deg": 40.1,
      "sunlit_at_max": null
    }
  ],
  "pass_count": 1
}
```

Errors: `404` if the satellite is not in the current catalogue, `422` for
validation errors (bad coordinates, excessive duration, naive datetime).

## `POST /schedule/generate`

**Request body**
```json
{
  "ground_station": { "...": "..." },
  "requests": [
    {
      "request_id": "REQ-1",
      "norad_id": 5,
      "satellite_name": "VANGUARD 1",
      "priority": "HIGH",
      "earliest_start_utc": "2026-07-12T00:00:00Z",
      "latest_end_utc": "2026-07-15T00:00:00Z",
      "min_elevation_deg": 10,
      "min_contact_seconds": 60
    }
  ]
}
```

`requests` must contain 1–50 items.

**Response 200** — see `ScheduleResult` in `backend/app/models/schemas.py`;
includes `scheduled[]` (with `reason` explaining selection),
`rejected[]` (with `reason` explaining rejection), and utilization stats.

---

## `POST /export/schedule?format=json|csv`

Body: a `ScheduleResult` object (as returned by `/schedule/generate`).
Returns the same data as a downloadable file (`Content-Disposition:
attachment`).

---

## Error format

All errors return:
```json
{ "detail": "human-readable message" }
```
or, for request validation errors:
```json
{ "detail": "Validation error", "errors": [ /* pydantic error list */ ] }
```
